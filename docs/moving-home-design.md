## 1. 当前实现

### 1.1 世界与坐标

- 逻辑视口 `LOGIC_W=640 / LOGIC_H=360`，世界 `WORLD_W=1600 / WORLD_H=1200`。
- 相机 `camX/camY` 跟随受控角色 `activeChar`，并 clamp 在世界内。
- 玩家、伙伴、敌人、子弹、掉落物、宝箱都存**绝对世界坐标** `x/y`。

### 1.2 家园与农场的存储

家园是唯一的可变原点，表示**家园左上角（0 号地块左上角）**的世界坐标：

```
const DEFAULT_HOME = { x: round(WORLD_W/2 - FARM_W/2), y: WORLD_H/2 + 52 };
let home = { x, y };              // 权威坐标，仅这里存位置
function homeCenter() { return { x: home.x + FARM_W/2, y: home.y + farmH()/2 }; }
```

- 地块仍**不存坐标**，位置由索引与 `home` 派生：
  `plotPos(i) = [home.x + col*36, home.y + row*36]`（`FARM_COLS=3`，步长 `FARM_CELL+FARM_GAP`）。
- 地块数量可增长：`plots` 动态数组，初始 9 块（`BASE_FARM_ROWS=3`），购买后向下补格、行满自动开新行。
- 家园高度随实际行数变化：`farmHFor(n)` / `farmH()`；家园可移动的下边界是 `homeMaxY() = WORLD_H - farmH()`。
- 家园中心、镇守圈、猫窝/狗窝、守卫巡逻全部从 `home` / `homeCenter()` 派生，不再有第二套坐标基准。

### 1.3 作物状态与生长计时

- `plots[i] = {state:'empty'|'growing'|'ready', crop, start}`。
- 生长只看 `farmTime - p.start`，与坐标完全解耦；移动家园不改写 `start`，正在生长的作物剩余时间不变。
- 地块无碰撞，角色可以穿过；移动家园不需要清空或重排地块。

### 1.4 存档（v4）

- `SAVE_KEY='pixel-farm-save-v1'`（键名不随版本变），`SAVE_VERSION=4`。
- 新增并保存 `home:{x,y}`；地块按实际数量保存（9..200）。
- 兼容 v1/v2/v3：旧档读入时回填默认家园 `(747,652)`；旧档按原规则校验 9 块地。
- 迁移防护：
  - 读旧档升级前先备份原文：v1/v2 → `pixel-farm-save-backup-v2`，v3 → `pixel-farm-save-backup-v3`；
  - 读档失败调用 `failLoad`，置 `saveBlocked` 并在 `#saveerr` 可见提示，**绝不静默覆盖**原档；
  - 下一次成功写盘即升级为 v4。
- 家园坐标读入时 `clamp` 到 `[0, HOME_MAX_X] × [0, homeMaxY()]`，非法值回填默认、不判损坏。

## 2. 家园怎么移动（已实现）

- 入口：按 `H` 或点 HUD「在此安家」；`gameState` 切到 `homemove` 并暂停。
- 目标位置：以玩家当前位置为家园中心，左上角 `x/y` 先计算再裁剪进世界边界。
- 限制：与当前家园中心距离 `< 120px` 时拒绝并飘字提示「离得太近，至少 120px」。
- 确认面板显示搬迁距离和八方向；`Enter` / 确认按钮执行，`Esc` / 取消关闭。
- 确认后：
  - `home` **立即**赋新值，不做平移补间（历史设计中的 0.35s 补间已移除）；
  - 地块与作物下一帧整体落到新位置；
  - 狗窝随家园重置到新位置；守卫任务的伙伴同步到新家园附近；
  - 立即 `saveGame()` 写档；飘字「家园已迁至此地」。
- 取消或距离不足时不产生任何存档写入。

### 2.1 扩张与下边界

- 买地时若 `home.y + 新行高度 > WORLD_H - 10`，家园会**自动上移**刚好容纳新行的距离，无需手动按 H；守卫伙伴同步平移。
- 若家园已贴地图上边界仍放不下新行，则拒绝购买并提示空间不足。

## 3. 与其他系统的接缝（现状）

1. **守卫任务**：接战判定、找敌、拉回、巡逻与守卫圈渲染统一读 `homeCenter()`；家园搬迁后自动跟随。
2. **猫/狗**：猫窝、狗窝位置都由家园派生，家园移动后自动跟到新家园；狗会自行走回活动半径。
3. **挖宝 / 宝箱 / 敌人生成**：均以受控角色为中心，与世界坐标相关，与家园位置无关。
4. **出生点/相机**：`Actor` 出生点仍固定 `(800,600)`，`reset` 不随家园变化。
5. **地图/小地图**：当前没有实现；若未来做，家园用 `homeCenter()` 作为 POI 即可。
6. **HUD**：HUD 显示「在此安家 (H)」，搬迁确认面板显示距离与方向；不显示区域名。

## 4. 明确的非目标（本版仍不做）

- 不做家园实时跟随玩家、不做拖拽式自由摆放。
- 不做多家园、多据点。
- 不做地图/小地图 UI。
- 不改作物经济（成本/售价/生长时间/行情公式/`farmTime` 语义）。
- 不做家园/地块碰撞与地形改动。
- 不改伙伴数量（仍为 1），不做「一个伙伴一个家园」。
- 不做搬迁过渡动画与音效。
