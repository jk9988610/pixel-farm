# 第 3 批次计划（PLAN-03）

上游：[ROADMAP.md](ROADMAP.md) · 上一批次：[PLAN-02.md](PLAN-02.md) · 记录：[WORKLOG.md](WORKLOG.md)

## 批次总目标

把第 2 批次形成的「昼夜一局」补成**能算账、能看清结算、节奏不塌**的循环：

- B8 商店经济最小闭环（种子买 / 作物卖 / 库存与金币校验）；
- B9 清晨结算面板（替代只有飘字）；
- B10 昼夜数值节奏调整（白天不再完全没有敌人，夜晚有梯度）；
- B11 发布包排除 `_scripts/`（低风险、可验证才做）。

顺序 **B8 → B9 → B10 → B11**：先有库存才能让结算与节奏调整有意义；B11 只动打包，最后做。

## B8 · 商店经济最小闭环

| 项 | 内容 |
| --- | --- |
| 目标 | 金币不再「收获即到账」：收获进入作物库存，种子需先在商店购买；商店支持买种子、卖作物，价格来自 `CROPS` 表，交易失败有明确提示。 |
| 验收标准 | ① 买种子：金币减少 `cost`，对应种子 +1，金币不足时提示「金币不足」且数值不变；② 播种消耗 1 个种子，种子为 0 时提示「种子不足」且不扣金币；③ 收获后作物库存 +1（不再直接加金币），并照旧给经验；④ 卖 1 个 / 卖全部：库存减少、金币按 `sell` 增加，库存为 0 时提示「没有可卖的作物」；⑤ 金币、种子、作物库存刷新页面后完全保持。 |
| 实现要点 | `seeds` / `produce` 两个长度 3 的数组；`B` 打开商店面板（同时暂停），`Esc` 或 `B` 关闭；面板按钮直接调用 `buySeed(i)` / `sellProduce(i, all)`；存档追加可选字段 `seeds` / `produce`（旧档缺省给初始库存）。 |
| 涉及文件 | `demo/play.html` |
| 预估工作量 | 1 人日 |
| 风险 | 改为库存制会让老档的「已收获金币」与新档体验不同（老档金币保留，属预期）；若默认库存给太多会让经济失去压力 → 初始库存取 5/3/2，够走完第一轮。 |

## B9 · 清晨结算面板

| 项 | 内容 |
| --- | --- |
| 目标 | 清晨不再只有飘字：弹出结算面板，显示当夜击杀数、击杀奖励金币、实际回血值，确认后关闭并继续白天。 |
| 验收标准 | ① 入夜 → 清晨时弹出「清晨结算」面板；② 面板中的击杀数与 HUD「夜战击杀」在入夜到清晨期间累计的数值一致；③ 奖励金币 = 击杀数 × 2，结算后金币实际增加同值；④ 回血显示为实际恢复量（满血时为 0）；⑤ 点击「确认收工」或按 Enter 关闭，游戏恢复；不确认时游戏保持暂停。 |
| 实现要点 | 新增 `gameState='settle'` 分支（只渲染 + 不推进逻辑）；`startDay()` 计算并写入 DOM 后进入该状态；确认后回 `playing` 并写档。 |
| 涉及文件 | `demo/play.html` |
| 预估工作量 | 0.5 人日 |
| 风险 | 结算暂停会让夜晚结束后的画面停住，需要 HUD/阶段倒计时同步显示「白天」避免误解；自动确认不做（保持玩家主动），若长期不确认则一直暂停（可接受）。 |

## B10 · 昼夜数值节奏调整

| 项 | 内容 |
| --- | --- |
| 目标 | 解决「白天完全没有敌人 → 升级过慢 → 夜晚打不动」的问题；给出可复核的数值表，并让夜晚随天数有梯度。 |
| 验收标准 | ① 白天每约 4s 生成 1 只弱敌（仅前 3 种），约 12 只/白天；② 白天击杀同样掉经验宝石，等级增长明显快于第 2 批次；③ 夜晚生成间隔 0.9s → 最低 0.30s，入夜仍有 Boss；④ 第 N 天夜间敌人 HP ×(1+0.10×(N-1))，Boss HP = 150 + 70×(N-1)；⑤ 天数随清晨递增并写入存档；⑥ 无控制台报错。 |
| 实现要点 | `dayNumber`（从 1 起）；`DAY_LEN=50`、`NIGHT_LEN=40`；白天生成走 `spawnEnemy(true)`（只取弱敌）；`spawnEnemy` 内按天数乘 HP；`spawnBoss` 改为按天数计算血量。 |
| 涉及文件 | `demo/play.html` |
| 预估工作量 | 0.5 人日 |
| 风险 | 白天有敌人会让「种田」不再安全，需要在白天把敌人数量压低（4s/只、只取弱敌）；玩家完全不战斗时白天会积累少量敌人，清晨清场可兜底。 |

### B10 数值表（调整前后对照）

| 项 | 第 2 批次 | 第 3 批次 | 依据 |
| --- | --- | --- | --- |
| 白天时长 | 45s | 50s | 留出播种 + 收获一轮（萝卜 20s）的时间 |
| 夜晚时长 | 35s | 40s | 让「击杀 → 结算」有足够样本，避免一夜只杀 2-3 只 |
| 白天敌人 | 无 | 每 4s 一只弱敌（约 12 只/白天） | 只补升级速度，不改变「白天以种田为主」的定位 |
| 夜晚生成间隔 | 0.9s → 0.18s | 0.9s → 0.30s | 上一批次后半段过密，玩家在低等级时难以站住 |
| 夜间敌人 HP | 固定 | ×(1 + 0.10×(天数-1)) | 让「多活一天」有难度回报，同时首日不变 |
| Boss HP | 150 + gameTime×1.5 | 150 + 70×(天数-1) | 去掉随时间线性膨胀（夜晚变长后过强），改按天梯度 |
| 升级来源 | 夜战经验宝石 | 夜战宝石 + 白天少量击杀 + 收获经验（沿用） | 白天不再是纯等待 |
