# 第 2 批次计划（PLAN-02）

上游路线图：[ROADMAP.md](ROADMAP.md) · 批次记录：[WORKLOG.md](WORKLOG.md)

## 批次总目标

在「农场闭环已可用」的基础上，把**工程可靠性**补齐，并迈出**昼夜双循环的第一步**：

1. 存档不再被多标签页互相覆盖（B5）；
2. 部署可原子切换、失败可回滚（B6）；
3. 白天种田 / 夜晚来袭 / 清晨结算的最小闭环成立（B7，M1 切片）。

批次顺序固定为 **B5 → B6 → B7**：B6 会改部署脚本，必须在 B5 的存档逻辑稳定后再动；B7 会产生最多内容改动，放最后，方便用前两项的稳定部署链路收尾。

## B5 · 修复多标签页存档互相覆盖

| 项 | 内容 |
| --- | --- |
| 目标 | 同源多标签打开同一游戏时，只允许一个「活动标签」写存档；其余标签进入「待命（只读）」，不写 `localStorage`。切换标签时明确提示并可接管，接管后加载最新存档，不丢进度。 |
| 验收标准 | ① 同时开两个标签：第一个正常游戏，第二个显示「另一个标签页正在游戏」覆盖层并暂停逻辑；② 在第二个标签做播种/暂停等操作，`localStorage` 中的存档不被待命标签覆盖（`savedAt` 不变）；③ 点击「在此标签页继续」后，第二个标签接管并显示第一个标签已保存的金币/地块；④ 关闭活动标签后，待命标签在锁过期（≤10s）内可正常接管；⑤ 单标签场景行为与第 1 批次一致。 |
| 实现要点 | `localStorage` 键 `pixel-farm-lock-v1` 存 `{ tab, at }`；每 2s 心跳刷新 `at`；锁超过 8s 视为失效；`storage` 事件监听锁键与存档键；`saveGame()` 增加 `isActiveTab` 守卫；接管按钮重新 `loadGame()` + `reset(true)`。 |
| 涉及文件 | `demo/play.html` |
| 预估工作量 | 0.5–1 人日 |
| 风险 | `storage` 事件不跨标签在部分浏览器/隐身模式失效 → 退化为心跳锁，仍是单写；接管时整局重置会丢失「本局进行中的敌人/子弹」，属于可接受范围，需在 UI 写明「接管会载入最近存档」。 |

## B6 · 部署脚本原子切换

| 项 | 内容 |
| --- | --- |
| 目标 | 部署不再 `rm -rf` 线上目录：上传到带时间戳的新目录（release）→ 校验文件数 → 通过软链原子切换 docroot；切换后验证 HTTP，失败自动回滚到上一版。 |
| 验收标准 | ① 新脚本部署成功时：`/var/www/play.bykc.click` 为软链指向 `/var/www/play.bykc.click.releases/<时间戳>`，站点 200；② 人为制造失败（如上传错误包/解压失败）时脚本返回非 0，线上仍是上一版且 `play.html` 200；③ 保留最近 3 个 release，清理更早目录；④ 旧脚本保留为 `deploy-legacy.py`，可用 `python deploy-legacy.py` 复现旧行为。 |
| 涉及文件 | `deploy.py`、`deploy.cmd`、新增 `deploy-legacy.py` |
| 预估工作量 | 0.5–1 人日 |
| 风险 | docroot 从真实目录改为软链，需要 nginx 允许跟随软链（`disable_symlinks off` 为默认）；若服务器上 docroot 被其他配置引用为真实路径，切换后需人工确认。首次切换前必须做 tar 备份。若验证不通过，保留旧脚本并回滚软链。 |

## B7 · 昼夜双循环最小闭环（M1 第一步）

| 项 | 内容 |
| --- | --- |
| 目标 | 一局内形成明确节奏：**白天**（限时，不出敌人，可种田/收获）→ **夜晚**（敌人与 Boss 来袭，复用现有战斗）→ **清晨结算**（按夜晚击杀给金币、按存活回血、清场）→ 回到白天。阶段与倒计时在 HUD 可见，状态可存档。 |
| 验收标准 | ① HUD 显示当前阶段与剩余秒数；② 白天无新敌人生成，夜晚按原有节奏生成；③ 阶段切换有画面提示（「夜幕降临 / 清晨结算 +N 金币」）；④ 清晨结算金币进入存档，刷新后仍保留；⑤ 夜晚击杀计数与总击杀分离，结算后夜晚计数归零；⑥ 死亡重开仍保留农场/金币/等级（第 1 批次行为不回退）。 |
| 实现要点 | `phase`（`day`/`night`）+ `phaseT` 倒计时；白天 45s、夜晚 35s（常量可调）；夜晚首帧刷一只 Boss；清晨移除敌人/弹幕/子弹、`coins += nightKills * 2`、回血 15%；存档追加可选字段 `phase`、`phaseT`（缺省按白天处理，保持 v1 向后兼容）。 |
| 涉及文件 | `demo/play.html` |
| 预估工作量 | 1–1.5 人日 |
| 风险 | 白天禁止生成会降低升级速度，可能让夜晚难度曲线失衡 → 先用小数值试跑，必要时提高夜晚经验宝石价值；存档新增字段必须向后兼容，否则旧档会被判损坏。 |

## 本批次明确不做的事

- 不做 M2 商店/种子买卖/工具升级（B7 只做结算给金币，不做消费侧）。
- 不做浇灌、肥料、土地等级、建筑、动物。
- 不做模块拆分（`demo/src/`）、不引入任何依赖或构建工具。
- 不做音频、不做完整移动端适配（触屏摇杆维持第 1 批次状态）。
- 不重跑 Aseprite PNG 生成，B7 的昼夜表现只用 Canvas 叠加色，不新增美术资源。
- 不改 `README.txt`、不处理未跟踪的 `_aseprite_test/`、不 push。
