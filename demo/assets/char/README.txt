================================================================
  assets/char/  角色精灵帧目录
================================================================

本目录存放游戏中所有可操控角色的逐帧动画素材。
play.html 启动时会读取 manifest.json, 按需加载 PNG 并播放动画。

----------------------------------------------------------------
目录结构
----------------------------------------------------------------

assets/char/
├── manifest.json            索引文件 (由 tools/art/gen_char_manifest.py 生成, 勿手改)
├── README.txt               本文件
└── <角色名>/                一个文件夹 = 一个角色
    ├── idle/                站立 (无方向, 通用)
    │   ├── frame_0.png
    │   └── frame_1.png
    ├── walk/                行走 (无方向, 通用)
    │   ├── frame_0.png .. frame_3.png
    ├── jump/                跳跃 (无方向, 通用)
    │   └── frame_0.png .. frame_2.png
    ├── down/                朝下 (面向镜头)
    │   ├── idle/  frame_0.png, frame_1.png
    │   └── walk/  frame_0.png .. frame_3.png
    ├── up/                  朝上 (背向镜头)
    │   ├── idle/  ...
    │   └── walk/  ...
    └── side/                侧面 (左右共用, 引擎按 dir 翻转)
        ├── idle/  ...
        └── walk/  ...

注意: 顶层 idle/walk/jump 是无方向的通用动画;
      down/up/side 下的 idle/walk 才是分四方向的动画。
      play.html 优先使用带方向的 (this.facing -> down/up/side),
      缺失时回退到顶层通用帧, 再缺失则回退到色块小人。

角色属性在 play.html 的 reset() 中根据 usingChar 微调。

----------------------------------------------------------------
帧规范
----------------------------------------------------------------

- 每帧 PNG 尺寸必须完全相同 (建议 32x32 或 32x48)
- 文件名: frame_0.png, frame_1.png, frame_2.png ... (按字典序排序)
- 背景透明, 像素对齐
- idle   建议 2 帧   (呼吸/微动循环)
- walk   建议 4 帧   (抬脚-落脚循环, 引擎 8fps 播放)
- jump   建议 3 帧   (起跳/空中/落地, 当前未接入引擎, 备用)
- 方向数: down / up / side (side 左右翻转共用)
- 帧数任意, 引擎按 frameIdx % length 循环

----------------------------------------------------------------
manifest.json
----------------------------------------------------------------

由 tools/art/gen_char_manifest.py 扫描本目录自动生成, 结构:

{
  "generated": "生成时间",
  "characters": {
    "<角色名>": {
      "down": { "idle": ["down/idle/frame_0.png", ...],
                "walk": ["down/walk/frame_0.png", ...] },
      "up":   { ... },
      "side": { ... }
    },
    ...
  }
}

脚本只收录 down/up/side 三个方向 + idle/walk/jump 三个动作,
顶层无方向的 idle/walk/jump 不写入 manifest (仅作画图参考)。

----------------------------------------------------------------
工作流
----------------------------------------------------------------

1. 画图: 在 <角色名>/<方向>/<动作>/ 下放 frame_*.png
2. 生成索引:
       python tools/art/gen_char_manifest.py
   (脚本从自身位置推导仓库根, 可在任意目录执行)
3. 刷新 play.html 即可看到新角色/新动画

----------------------------------------------------------------
引擎加载逻辑 (play.html)
----------------------------------------------------------------

- boot() 调用 loadAllChars(): fetch manifest.json -> 逐角色逐帧 loadImg
- 每个角色的首帧尺寸记为 frameW / frameH, 用于绘制锚定
- usingChar 默认选 'villager', 否则取列表第一个
- Player.draw(): 按 this.facing 取方向组, 取 this.state 动作组,
  按 frameIdx 取帧; side 方向根据 this.dir 做水平翻转
- 无角色素材时回退到色块小人 (绿身 + 肤色头)

----------------------------------------------------------------
约定
----------------------------------------------------------------

- 不要手动编辑 manifest.json, 画完图跑脚本即可
- 新增角色只需建文件夹 + 放帧 + 跑脚本, 无需改代码
- 如需改角色属性, 编辑 play.html 的 reset() 里的 usingChar 分支
